개인정보처리방침

시행일: 2026년 10월 11일 (인스타그램 항목 추가: 2026년 10월 14일)

이 방침은 한누리 디지털 교육(이하 "운영자")이 만든 업로드 도구 hannuri-upload와 인스타그램 도구 Hannuri Auto Publisher(이하 함께 "앱")에 적용됩니다.

1. 앱의 목적

앱은 운영자가 직접 제작한 교육 영상을 운영자 본인의 유튜브 채널·페이스북 페이지·인스타그램 계정(@1nuri_education)에 올리고, 제목·설명·자막·썸네일을 관리하며, 인스타그램 게시물에 댓글을 남긴 분께 요청하신 자료(가이드북) 링크를 메시지로 한 번 보내기 위한 내부 도구입니다. 일반 사용자에게 제공하는 서비스가 아닙니다.

2. 사용하는 정보

  • 운영자 본인 계정의 OAuth 인증 토큰(업로드 권한)
  • 운영자 채널의 기본 정보(채널 이름·ID)와 운영자가 올린 영상의 정보

인스타그램에서는 운영자 게시물에 댓글을 남긴 분의 댓글 ID와 인스타그램 사용자 ID를 읽습니다. 같은 분께 메시지를 두 번 보내지 않도록 이 ID만 기록하며, 이름·연락처 등 그 밖의 개인정보는 수집하지 않습니다.

3. 정보의 사용과 보관

인증 토큰은 운영자의 컴퓨터와 운영자의 비공개 GitHub 저장소 보안 설정(Secrets)에만 저장되며, 운영자 계정에 콘텐츠를 올리고 자료 링크를 보내는 용도로만 사용합니다. 인스타그램 댓글 ID·사용자 ID 기록도 같은 비공개 저장소에만 보관합니다. 제3자에게 판매·공유·전송하지 않습니다.

4. Google·YouTube API 사용

앱은 YouTube API 서비스를 사용합니다. 앱을 사용하면 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다. Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 인스타그램(Meta) API 사용

앱은 Instagram API(Meta)를 사용하며, Instagram 개인정보처리방침과 Meta 플랫폼 약관을 따릅니다. 메시지는 Instagram이 허용하는 범위(댓글 7일 이내, 댓글당 1통)에서만 보냅니다.

6. 데이터 삭제 요청

기록된 댓글 ID·사용자 ID의 삭제를 원하시면 아래 문의 메일로 인스타그램 아이디를 알려 주세요. 확인 후 7일 이내에 삭제합니다. 댓글을 지우셔도 이후 메시지는 보내지 않습니다.

7. 권한 철회

앱에 준 권한은 언제든지 Google 계정 → 연결된 앱(페이스북은 설정 → 비즈니스 통합, 인스타그램은 설정 → 앱 및 웹사이트)에서 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 쓸 수 없습니다.
