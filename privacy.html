개인정보처리방침

시행일: 2026년 10월 11일

이 방침은 한누리 디지털 교육(이하 "운영자")이 만든 업로드 도구 hannuri-upload(이하 "앱")에 적용됩니다.

1. 앱의 목적

앱은 운영자가 직접 제작한 교육 영상을 운영자 본인의 유튜브 채널과 페이스북 페이지에 올리고, 제목·설명·자막·썸네일을 관리하기 위한 내부 도구입니다. 일반 사용자에게 제공하는 서비스가 아닙니다.

2. 사용하는 정보

  • 운영자 본인 계정의 OAuth 인증 토큰(업로드 권한)
  • 운영자 채널의 기본 정보(채널 이름·ID)와 운영자가 올린 영상의 정보

앱은 시청자나 다른 사람의 개인정보를 수집하지 않습니다.

3. 정보의 사용과 보관

인증 토큰은 운영자의 컴퓨터에만 저장되며, 운영자 채널에 영상을 올리는 용도로만 사용합니다. 제3자에게 판매·공유·전송하지 않습니다.

4. Google·YouTube API 사용

앱은 YouTube API 서비스를 사용합니다. 앱을 사용하면 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다. Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 권한 철회

앱에 준 권한은 언제든지 Google 계정 → 연결된 앱(페이스북은 설정 → 비즈니스 통합)에서 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 쓸 수 없습니다.
